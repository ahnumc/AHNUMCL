AHNUMCL 遵循[语义化版本规范 2.0.0](https://semver.org/lang/zh-CN/)。

## 1.1.0

`2026-10-20`

- 🌟 支持安装和管理 Cleanroom 加载器，并匹配 Java 运行时选择与自动下载要求。
- 🌟 为启动页按钮添加液态玻璃效果，并支持在皮肤查看器中保存皮肤图片。
- 🌟 支持按设定的延时自动关闭游戏崩溃提示窗口。
- 🐛 恢复内置 WebP 壁纸显示，修复窗口透明度滑条无效的问题，将透明度应用于壁纸层并保持文字与控件清晰。
- 🐛 支持 Minecraft 26.x 世界数据，以及省略可选元数据字段的 Quilt 整合包。
- 🐛 修复受支持加载器子目录中的模组管理、启用或禁用模组后的文件路径，以及模组更新弹窗。
- 🐛 修复 NeoForge 实例的本地账号自定义皮肤问题，并在世界加载失败时保留资源包缓存。
- 🐛 修复启动弹窗顺序和长玩家名挤压头像的问题，无账号启动时跳转至账号设置。
- 🚀 通过折叠区域延迟渲染、模组版本增量加载及避免重复解析模组元数据，减少不必要的开销。
- 🚀 启动时自动清理过期下载缓存。
- 🛠 更换服务器状态查询库，并更新 Minecraft 版本列表与模组元数据。
- 📦 更新 Tauri、Next.js、MCP 及相关依赖，修复 Rust 依赖安全公告涉及的问题，并将最低 Rust 版本提升至 1.98.1。

## 1.0.5

`2026-08-19`

- 🌟 恢复 AHNUMC 服务器整合包在实例安装流程中的自动导入。
- 🚀 优化版本与实例安装流程的阻塞问题，并减少嵌套弹窗渲染，提升界面响应速度。
- 🐛 修复嵌套依赖弹窗流程，并延迟状态更新中的副作用，确保资源安装更稳定。
- 🐛 平滑下载任务速度的突发波动，提升高负载下任务表现的稳定性。
- 🐛 移除账号入口中的 LittleSkin 登录选项。

## 1.0.4

`2026-08-17`

- 🚀 提升自动下载并发，增加可靠重试与 HTTP Range 断点续传，提高下载速度和稳定性。
- 🚀 参照 PCL-CE 的超时与回退顺序智能选择官方源和镜像源，直连较快时优先使用直连。
- 🐛 修复 CurseForge API 与 CDN 访问、无代理导入整合包以及下载进度停滞或大小未知时的显示问题。
- 🐛 修复包含特殊字符的 CurseForge API Key 被截断，并为 Authlib-Injector 元数据和 JAR 下载增加镜像回退。
- 🌟 在实例设置中新增 latest.log 查看器，支持搜索、复制和直接打开日志文件。
