AHNUMCL 遵循[语义化版本规范 2.0.0](https://semver.org/lang/zh-CN/)。

## 1.0.5

`2026-08-19`

- 🌟 恢复 AHNUMC 服务器整合包在实例安装流程中的自动导入。
- 🚀 优化版本与实例安装流程的阻塞问题，并减少嵌套弹窗渲染，提升界面响应速度。
- 🐛 修复嵌套依赖弹窗流程，并延迟状态更新中的副作用，确保资源安装更稳定。
- 🐛 平滑下载任务速度的突发波动，提升高负载下任务表现的稳定性。
- 🐛 移除账号入口中的 LittleSkin 登录选项。

## 1.0.4

`2026-08-17`

- 🚀 提升自动下载并发，增加可靠重试与 HTTP Range 断点续传，提高下载速度和稳定性。
- 🚀 参照 PCL-CE 的超时与回退顺序智能选择官方源和镜像源，直连较快时优先使用直连。
- 🐛 修复 CurseForge API 与 CDN 访问、无代理导入整合包以及下载进度停滞或大小未知时的显示问题。
- 🐛 修复包含特殊字符的 CurseForge API Key 被截断，并为 Authlib-Injector 元数据和 JAR 下载增加镜像回退。
- 🌟 在实例设置中新增 latest.log 查看器，支持搜索、复制和直接打开日志文件。

## 1.0.3

`2026-08-16`

- 🌟 新增启动器主体色自定义功能，提供预设色板和自定义颜色输入。
- 🌟 新增界面字体与日志字体选择、可搜索的自定义字体以及字体大小调节。
- 🌟 新增独立的浅色与深色界面背景色板，支持自定义颜色和透明度调节。
- 🌟 新增窗口透明度设置，并优化滑块拖动，避免拖动时连续写入配置。
- 🌟 新增 AHNU Flowy 深浅色壁纸组，并将其设为默认背景。
- 🐛 隐藏非活动 Windows 窗口的标题栏控件，避免透明窗口重叠时控件透出。
- 🐛 将残留的 SJMCL 标签和默认数据目录名称替换为 AHNUMCL 品牌。

## 1.0.2

`2026-08-16`

- 🌟 支持通过 Yggdrasil Connect 设备授权登录 AHNUMC Skin。
- 🌟 更换压缩后的 WebP 内置壁纸，并将赭山门设为默认背景。
- 🌟 恢复 MUA 社区新闻源，并改进社区新闻请求的重试处理。
- 🐛 修复开发工具栏展开与收起不稳定的问题。

## 1.0.1

`2026-08-15`

- 🌟 在实例页面新增 AHNUMC 服务器列表，并支持一键安装客户端整合包。
- 🌟 新增 AHNUMC 第三方账号登录，移除必须优先使用微软登录的限制。
- 🌟 新增 GitHub 下载镜像设置、自动测速与最快镜像选择。
- 🛠 将内置服务器列表和新闻源迁移至 AHNUMC API。
